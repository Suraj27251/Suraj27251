## 🧭 About

I help businesses find **operational problems**, trace the **root cause**, and turn them into
practical improvements through better **processes, systems, data, and automation**.

With **5+ years** in business analysis and operations, I work across ERP and CRM systems,
requirements analysis, BPMN process mapping, data analytics, workflow automation, and stakeholder
management. I don't reach for automation first — I trace a symptom back to the process, data, or
system decision that caused it, then choose the fix.

   - github-readme-stats.vercel.app is a shared community instance and is
     frequently rate-limited. If a card renders as "error" or an empty box:
       a) wait — the limit resets within the hour;
       b) self-host: fork anuraghazra/github-readme-stats, deploy to Vercel,
          and swap the host in every URL;
       c) change the theme: ?theme=radical also accepts dark, tokyonight,
          dracula, gruvbox, etc.
     The streak card and the summary card are SEPARATE services, so one
     failing does not take the others down.
   - image.pollinations.ai: the free tier enforces rate limits per IP. The
     hero banner is cached by GitHub's camo proxy after the first view, so
     in practice it renders — but if it ever breaks, the alt text carries
     the meaning rather than leaving a mystery gap.

   srcset/src values with relative paths such as "./assets/hero-dark.jpg".
   GitHub then serves them straight from the repo with zero third-party risk.
